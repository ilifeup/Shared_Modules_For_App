# ADR-002 — Approved S1-A minimal vertical slice

Date: 2026-10-23
Status: Approved for S1 scope; security and migration details require separate review.

User explicitly approved option A: **Filament administrator creates a synthetic test member → Flutter login → view and edit own display name → view administrator-published member notices → logout**. Use no-cost local/CI test infrastructure. No public registration, email verification, VIP, booking, check-in or payments.

## Implementation boundary
- Shared repo may implement disposable Flutter/Laravel/Filament PoC and automated tests for this sequence.
- Three production Apps remain separate; Tiandi integration is later S2, not part of this approval.
- Laravel Sanctum bearer tokens, Spatie Permission/Policies, secure Flutter token storage, and shared response envelope are planned baseline. Exact auth session expiration, persistent schema, admin role details and public API contract need review before locking them.
- No production migration, paid service, deployment or iStudy access.

## Acceptance
Document real backend tests, Flutter tests, API ↔ DB ↔ Filament integration, Android APK build and physical-device tests independently. A CI PASS is not evidence of real-device PASS.

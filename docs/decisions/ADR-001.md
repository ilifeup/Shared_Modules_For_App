# ADR-001 — Shared-first repository strategy

Date: 2026-10-23
Status: Confirmed direction; S0 implementation ongoing

Decision: use `ilifeup/Shared_Modules_For_App` as the canonical shared-code and API-contract repository. Develop the first Flutter + Laravel + Filament vertical slice here, then integrate into Tiandi first, Wuxiang second, EachCore third. All three Apps retain separate codebases, databases, authentication, business rules and deployments. This supersedes the historical Tiandi-first/no-fourth-repository direction **for future work only**; historical ADRs remain unchanged until a separate Tiandi governance PR records supersession.

Rationale: prove real reusable contracts and code before building App-specific implementations. No central backend or SSO is introduced.

Not authorized by this ADR: production deployment, new paid services, business-specific booking/check-in/verification policies, automatic PR merge without required checks, or edits to iStudy.

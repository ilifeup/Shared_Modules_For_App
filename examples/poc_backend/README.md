# S1 PoC backend (Laravel 13 + Sanctum + Filament 5)

Disposable host for the S1 shared modules. **Not a production backend.** Each App
(Tiandi, Wuxiang, EachCore) deploys its own copy with its own database, `APP_KEY`,
admin account and SMS credentials.

See the repository [README](../../README.md#s1-poc-快速啟動) for setup, the API list and settings.
